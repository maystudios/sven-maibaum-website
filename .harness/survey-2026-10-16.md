# Survey 2026-10-16

Read-only survey by a fresh agent (code facts) plus the controller's own checks (deploy state, live
bundle, lockfile). Code was trusted over documents.

## What the product does

Personal website of Sven Maibaum (MAY STUDIOS, sole proprietorship, Burscheid): home page with Hero,
About, Philosophy, Experience, Projects, Publications, Skills and Contact; ten project pages under
`/projekte/*`; a standalone social links page `/links`; a shareable business card `/visitenkarte`
(noindex); `/showcase`, `/agb`, `/impressum`, `/datenschutz`; 404. Contact form via EmailJS.

## Stack

Vite 7.3.1, React 19.2.4, React Router DOM 7.13.0, TypeScript 5.9.3 (strict), Tailwind CSS 3.4.17,
Motion 12.34.3, `@emailjs/browser` 4.4.1, lucide-react, qrcode.react (versions from
`package-lock.json`). `scripts/prerender.mjs` writes per-route HTML with metadata for 14 routes plus a
404 fallback. GitHub Pages via Actions on push to `main`; public repo `maystudios/sven-maibaum-website`.

## Store and backend identity

No backend. Hosting GitHub Pages, domain `sven-maibaum.com` (www redirects). EmailJS for mail (account
owner and connected mailbox unverified).

## Test surface

No test framework. `npm run lint` (0 errors, 1 warning in `src/components/Layout.tsx:16`) and
`npm run build` (passes, 2026-10-16) are the only machine checks. The owner decided on 2026-10-16 to
add Vitest and Playwright.
